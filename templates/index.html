About the pipeline

01

Data loading

GEO series matrix parsed; log₂(x+1) transform; top 5,000 high-variance probes retained.

02

Label extraction

Sample titles parsed from !Sample_title; "control" → 0, "case" → 1; 80/20 stratified split.

03

Feature selection

mRMR (top 200) · LASSO-CV · RF importance (top 100) · SVM linear weights (top 150).

04

Rank aggregation

Voting across all four methods; genes scored by number of lists they appear in.

05

Stability selection

50 bootstrap rounds; genes with stability ≥ 0.15 kept; panel capped at 25 biomarkers.

06

SMOTE + PCA

Minority class oversampled via k-NN interpolation; PCA retains components at 95 % variance.

07

Classifiers

SVM (linear, Platt scaling) · RF (200 trees) · Logistic Regression · GradientBoost (150 cycles).

08

Output

Majority vote across test samples; posterior probability as confidence; AUC, sensitivity, specificity reported.
